# 💻 arq2

Este repositório reúne todo o material acadêmico e laboratórios realizados na disciplina **Arquitetura de Computadores II**. O objetivo é centralizar os guias, exercícios e arquivos de teste utilizados nas aulas e nas avaliações.

## 🧠 Objetivo

Este material serve como suporte de estudo para entender:
- Fundamentos de lógica digital e organização de computadores
- Linguagem Verilog para descrição de hardware
- Técnicas de simulação e verificação de circuitos

## 📑 Estrutura do Repositório
- **Trabalhos Laboratório (LABs)**  
  Conteúdos resolvidos e guias propostos ao longo do curso.  
  ➜ [Acessar pasta](LABs)
  
- **Resumo de Artigo – LaTeX**  
  Arquivo em LaTeX contendo o esboço e o resumo estruturado do artigo solicitado.  
  ➜ [Acessar pasta](artigo)
